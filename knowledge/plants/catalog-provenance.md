# Catalog provenance

`src/plants/catalog.json` is generated by `scripts/plants/build-catalog.py` from two raw extracts kept next to it, both read on 2026-11-02:

| Field | Source | Coverage |
|---|---|---|
| `zone` | Gardyn's placement-by-zone guide | all 139 (138 guide lines; "Dragon Beans Green Beans" split into two plants) |
| `harvestMonths` | "First Harvest" on each yCube product page | 69 published; the rest use the category median and set `harvestEstimated` |
| `careLevel`, `yield` | "Care Level", "Yield" on product pages | 72 (store items only; null otherwise) |
| `inStore`, `gardynHandle` | yCube collection | 73 sold today |
| `succession` | Gardyn's succession table groups | exact when named there, else by category with `successionInferred` |
| `category`, `size`, `placement` | rules in the build script | `size: large` = fruiting/vining or sunflower; `placement` = cucumber exception |

No prose is copied: care notes are not in the catalog. Microgreens are excluded (Gardyn grows them in trays, not pods).

## Known gaps

- Harvest windows are months, not days; the sowing planner converts at 30 days per month.
- Succession gaps use the midpoint of Gardyn's ranges (10, 21, 31, 56 days); flowers have no fixed cadence.
- Gardyn's products change; re-run the extraction and the build script, then review the diff.
